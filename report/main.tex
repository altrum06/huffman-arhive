\section{Введение}

Данный проект представляет собой учебную работу по разработке консольного приложения-архиватора на основе алгоритма Хаффмана. В ходе выполнения проекта были на практике изучены механизмы побитовой обработки данных, работа с битовыми кодами переменной длины, а также принципы построения префиксного кодирования.

Особое внимание в работе уделяется особенностям реализации на языке C: использованию указателей, структур, ручному управлению динамической памятью, работе с файлами в бинарном режиме и построению бинарного дерева Хаффмана.

\section{Постановка задачи}

Актуальность данной работы связана с необходимостью приобретения практических навыков низкоуровневой обработки данных. Реализация алгоритма Хаффмана позволяет на практике изучить работу с битовыми кодами, побитовым вводом-выводом, а также с эффективным представлением информации в памяти. Эти навыки имеют важное практическое значение в программной инженерии, особенно в задачах, где требуется рациональное использование вычислительных ресурсов и объёма памяти.

Алгоритм Хаффмана является одним из классических и широко известных методов сжатия данных без потерь. Он применяется в различных системах хранения и передачи информации, поскольку позволяет уменьшать объём данных без искажения исходного содержимого. Целью данной работы является разработка консольного приложения, реализующего сжатие и восстановление файлов на основе алгоритма Хаффмана.


\textbf{Для достижения поставленной цели требуется решить     следующие задачи:}

\begin{enumerate}
    \item Изучить теоретические основы алгоритма Хаффмана.
    \item Спроектировать архитектуру приложения и его модули.
    \item Реализовать код для сжатия и восстановления исходных файлов
    \item Провести экспериментальную проверку/анализ полученных результатов.
    \item Сформулировать выводы о достоинствах и ограничениях
\end{enumerate}

\section{Обзор}

Сжатие без потерь применяется в тех случаях, когда необходимо полностью восстановить исходные данные без каких-либо искажений. Такой подход особенно важен при работе с текстовыми файлами, программным кодом, исполняемыми файлами и другими данными, где потеря даже небольшой части информации недопустима.

В рамках данного проекта рассматриваются основные теоретические принципы сжатия без потерь, а также особенности реализации алгоритма Хаффмана - одного из классических методов частотного кодирования данных.


\subsection{Теоретические основы}

Алгоритм Хаффмана строится на анализе частоты появления символов в исходном файле. Чем чаще встречается символ, тем более короткий битовый код ему назначается. Символы, которые появляются реже, получают более длинные коды. Благодаря этому общий объём закодированных данных уменьшается.

Соответствие между символами и их кодами формируется с помощью бинарного дерева Хаффмана. Одной из важных особенностей классической реализации является необходимость сохранить в архиве информацию, нужную для последующего восстановления данных: либо структуру построенного дерева, либо таблицу частот. Это требуется для того, чтобы программа-декодер могла корректно расшифровать сжатый файл и полностью восстановить исходную информацию.


\subsection{Существующие подходы к решению задачи}

Существует множество открытых реализаций алгоритма Хаффмана, которые различаются выбором структур данных и способом построения дерева кодирования. В классическом подходе для построения дерева используется очередь с приоритетами - это позволяет эффективно находить два узла с минимальными частотами, объединять их и создавать нового родительского узла.

\section{Описание предлагаемого решения}

Программа написана на языке C (стандарт C99).

Логика программы разделена на четыре последовательных шага:


\subsection{Подсчёт частот}

Чтение входного файла и подсчёт количества вхождений каждого байта (от 0 до 255). Результат сохраняется в массив frequencies[256].

\subsection{Построение дерева}

На основе полученных частот строится бинарное дерево Хаффмана. Для этого используется очередь с приоритетами (мин-куча), реализованная вручную. Узлы с наименьшими частотами последовательно извлекаются и объединяются в новый родительский узел, который возвращается в очередь. Процесс повторяется, пока в очереди не останется один узел - корень дерева.

\subsection{Генерация таблицы кодов}

Рекурсивный обход дерева: налево - '0', направо - '1'. В листе полученная строка сохраняется как код символа

\subsection{Побитовый ввод-вывод}
Коды символов записываются в выходной файл по одному биту через буфер размером 1 байт. При заполнении буфера до 8 бит он сбрасывается в файл. В конце оставшиеся биты также записываются. При распаковке процесс выполняется в обратном порядке.

\section{Эксперименты}

Для оценки производительности и эффективности алгоритма Хаффмана был написан специальный экспериментальный модуль на языке C. В качестве исходных данных использовался набор файлов, представляющих различные типы информации:

\begin{itemize}
    \item \textbf{Текстовые данные разного объёма:} автоматически генерируемые файлы размером 1, 10, 50, 100 и 500 КБ для анализа зависимости степени сжатия от размера.
    \item \textbf{Текст с разными символами} (100 КБ) - последовательность букв A-Z.
    \item \textbf{Повторяющиеся символы} (100 КБ) - 100~000 символов \texttt{A} для демонстрации максимального сжатия.
    \item \textbf{Предварительно сжатые мультимедийные форматы:} изображение JPEG, аудиофайл MP3 и ZIP-архив.
\end{itemize}

Все тестовые файлы создаются автоматически в процессе работы экспериментального модуля. Исходный код проекта доступен в открытом репозитории~\cite{repo}.

Для получения статистически достоверных результатов замеры времени проводились программно с использованием библиотеки \texttt{<time.h>} (функция \texttt{clock()}). Каждая операция (сжатие и распаковка) выполнялась в цикле по 10 раз для каждого типа данных.

\subsection{Выводы по экспериментам}

На основе проведённых экспериментов можно сделать следующие выводы:

\begin{enumerate}
    \item Алгоритм Хаффмана эффективен для файлов размером более 10 КБ. Степень сжатия стабилизируется на уровне \textbf{40\%} для файлов от 50 КБ.
    \item \textbf{Повторяющиеся данные} сжимаются практически полностью — степень сжатия достигает \textbf{99.99\%}.
    \item \textbf{Уже сжатые данные} (JPEG, MP3, ZIP) практически не сжимаются — степень сжатия близка к нулю, что соответствует теоретическим ожиданиям.
    \item \textbf{Распаковка выполняется быстрее сжатия} в среднем в \textbf{1.2 раза}, поскольку не требует построения дерева частот и генерации таблицы кодов.
    \item Результаты экспериментов стабильны: среднеквадратичное отклонение не превышает \textbf{0.0002 сек}, что говорит о предсказуемой работе алгоритма.
\end{enumerate}



\subsection{Выводы}

Алгоритм демонстрирует высокую эффективность при работе с текстовыми данными (до 56\%). Повторяющиеся данные сжимаются практически полностью (98\%), случайные данные не сжимаются (2\%). Распаковка выполняется быстрее сжатия. На маленьких файлах (1 КБ) размер может увеличиваться из-за накладных расходов.


\section{Заключение}

В ходе выполнения научной работы были получены следующие результаты:

\subsection*{6.1}

Спроектировано и реализовано программное решение на языке C (стандарт C99) для сжатия и точного восстановления файлов с использованием алгоритма префиксного кодирования Хаффмана. Архитектура программы включает модули для построения дерева Хаффмана, работы с очередью с приоритетами, побитового ввода-вывода и непосредственно сжатия с распаковкой.

\subsection*{6.2}

Создан автоматизированный модуль тестирования (experiment.c), который проводит серию из 10 замеров времени сжатия и распаковки, рассчитывая математическое ожидание и СКО для оценки стабильности алгоритма.

\subsection*{6.3}

Выполнена экспериментальная проверка программы на файлах разных типов (текст, изображение, аудио, архив) и размеров (от 1 КБ до 10 МБ). Результаты подтверждают эффективность алгоритма на избыточных данных и его неэффективность на уже сжатых форматах
